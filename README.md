## 📌 Project Overview
This project simulates a real-world automotive e-commerce platform offering essential engine components, brakes, tires, lighting, and exterior/interior accessories with a clean, rugged, and reliable UI/UX design.

---

## 🚀 Features Implemented

### Core Features:
- **Category-wise Product Display:** Dynamic navigation for Engine Parts, Brakes & Tires, Lighting & Electrical, and Accessories.
- **Product Search:** Real-time client-side search filtering by part name, brand, or category.
- **Cart & Quantity Adjustment:** Dynamic price calculation, tax computation, and LocalStorage persistence.
- **Checkout Process & Order Summary:** End-to-end checkout flow generating dynamic order records.

### Bonus Features:
- **Vehicle Garage Filter:** Filter parts tailored to specific vehicle models (Sedan, SUV, Truck).
- **Saved Wishlist:** Save items to wishlist and transfer to cart dynamically.
- **Order History:** View simulated past order tracking and statuses.

---

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3, Tailwind CSS (via CDN), JavaScript (ES6)
- **Data Storage:** JavaScript Arrays / LocalStorage (No Database Required)
- **Icons:** FontAwesome v6
